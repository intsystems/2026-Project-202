# Synthetic experiments

Controlled systems and validation runs with designed excitation, known phase counts, or fixed test conditions. The digits experiments use a real image dataset inside a controlled forcing protocol.

- [Controlled systems with known dimension](known_dimension/ReadMe.md). Five systems from the comparison in Table 6 of the article, from an oscillating matrix to constrained learning dynamics.
- [Digits and the validation protocol](validation_protocol/ReadMe.md). The main controlled experiments on handwritten digits, the fixed estimator configurations, and the zero-learning-rate check applied across systems.
- [Delay embedding and estimator limits](embedding_and_limits/ReadMe.md). Illustrations of delay reconstruction and experiments on lag, temporal exclusion, and the largest dimension that MG can track.
- [Robustness and trajectory measurement](robustness_and_measurement/ReadMe.md). Controls for interpreting changes in MG, tests with known dimension transitions, and validation of the trajectory sketch used to measure effective rank in the grokking runs.
- [Poster demonstrations](poster_demos/ReadMe.md). The two examples in Section 04 of the ASCOMP poster. Both have a controlled number of independent rhythms.
