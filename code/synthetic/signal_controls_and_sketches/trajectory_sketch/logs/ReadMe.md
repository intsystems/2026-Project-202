# Trajectory sketch validation data

Accuracy, timing, and storage measurements for the compressed trajectory used in the grokking study.

[Experiment overview](../ReadMe.md)

| CSV | What it contains |
| --- | --- |
| [`sketch_accuracy.csv`](sketch_accuracy.csv) | Participation ratio before and after compression at known ranks. |
| [`sketch_cost.csv`](sketch_cost.csv) | Storage size and elapsed time with and without sketch recording. |
| [`sketch_noninvasive.csv`](sketch_noninvasive.csv) | Column-by-column comparison of training logs collected with and without sketch recording. |
