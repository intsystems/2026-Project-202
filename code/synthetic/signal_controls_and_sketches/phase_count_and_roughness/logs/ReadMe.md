# Roughness and phase controls data

Known phase counts compared at matched signal roughness, and signal warps applied at a fixed phase count.

[Experiment overview](../ReadMe.md)

| CSV | What it contains |
| --- | --- |
| [`geometry_levels.csv`](geometry_levels.csv) | Estimates for signals with different phase counts and matched roughness. |
| [`geometry_switch_summary.csv`](geometry_switch_summary.csv) | Phase count, MG, and roughness by segment of the switch experiment. |
| [`geometry_switch_trace.csv`](geometry_switch_trace.csv) | Window-level trace through the change in phase count. |
| [`observer_warps.csv`](observer_warps.csv) | Estimates and roughness under monotone transformations of the observed signal. |
| [`verdict.csv`](verdict.csv) | Measured differences and pass indicators for the control comparisons. |
