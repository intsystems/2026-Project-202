# Dimension ceiling data

Sweeps over embedding dimension and record length that test where MG stops tracking the known rank.

[Experiment overview](../ReadMe.md)

| CSV | What it contains |
| --- | --- |
| [`ceiling_summary.csv`](ceiling_summary.csv) | Tracking limit, plateau, and diagnostics for each sweep setting. |
| [`ceiling_cells.csv`](ceiling_cells.csv) | Per-rank estimates, reference ranks, and diagnostics. |
| [`ceiling_fits.csv`](ceiling_fits.csv) | Fit errors for candidate explanations of the observed ceiling. |
| [`ceiling_slopes.csv`](ceiling_slopes.csv) | Measured and predicted slopes for the sweeps. |
