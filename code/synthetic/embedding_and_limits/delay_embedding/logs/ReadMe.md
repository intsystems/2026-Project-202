# Delay coordinate reconstruction data

Scalar signals, sample delay coordinates, and window estimates used to illustrate the method.

[Experiment overview](../ReadMe.md)

| --- | --- |

| [`curve_windows.csv`](curve_windows.csv) | MG, Levina?Bickel, roughness, and delay-space participation ratio by window. |
