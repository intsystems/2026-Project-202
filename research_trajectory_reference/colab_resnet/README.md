# E7 — Colab-бандл: MG-детектор упрощения на ResNet-18 / CIFAR-10

Перенос E5 (события по дозам) и E6 (онлайн-детектор) с маленькой CNN на ResNet-18.
Два сценария: обучение с нуля и дообучение предобученной модели. Протокол и
предсказания записаны до запуска — см. `PROTOCOL.md`.

## Как запустить

1. Загрузить `colab_resnet.zip` в Colab: панель Files или Google Drive.
2. Открыть `E7_resnet.ipynb`, выбрать runtime с GPU и выполнить ячейки по порядку.
   CIFAR-10 скачивается сам. Результаты пишутся на Drive в `e7_results/`. Если
   сессия оборвётся, достаточно перезапустить ячейку: готовые запуски пропускаются.
3. Забрать `e7_results/` целиком, вместе с `.npz`, и положить в
   `research_trajectory_reference/results_resnet/` — там же можно повторить анализ
   локально.

## Бюджет

Один запуск — 10 000 шагов — занимает на T4 примерно 6–10 минут. Полная сетка —
7 рукавов × 3 сида × 2 сценария = 42 запуска, около 5–7 часов GPU. Рукава в
ноутбуке идут по важности. Минимум, который уже проверяет предсказания P1–P2:
`base lr100 freeze_head prune80 batch_up` × 3 сида, только scratch — 15 запусков,
~2 часа.

## Файлы

| файл | что делает |
|---|---|
| `run_resnet.py` | обучение и логирование: норма параметров, loss, нормы слоёв, CountSketch обновлений |
| `analyse_resnet.py` | MG по окнам, таблица «до/после», PR обновлений, замороженный детектор |
| `detector_rule.json` | правило детектора, откалиброванное на CPU-сидах E4 (MG: M = 2, B = 3, δ = 0.088) |
| `code/actdim/estimator` | неизменённое ядро оценщика из проекта |
| `PROTOCOL.md` | предсказания P1–P3 |

Проверено локально на CPU: 40 шагов обучения каждого пути и полный анализ на
синтетических логах.
