# Applied time-series classification screen

New screening campaign after literature review of catch22/FFORMA. Fixed8 datasets: ECG200,ECG5000,TwoLeadECG,Wafer,FordA,ItalyPowerDemand,ChlorineConcentration,Earthquakes. Official UCR/UEA train/test archives only. No clinical deployment or universal superiority claim. Subjects/machines are not always identified by archive, so official test splits are not guaranteed subject-independent. Save archive hashes and downloads.

Compare: original20 temporal/spectral statistics (as HAR single), those+8 delay covariance PR features, those+PR+8 MG estimates, raw waveform RBF SVC, Euclidean1NN. Also MG-only descriptive. MG8 settings E4/8/12/20 crossed with tau1/2,k10,Theiler=max(10,span),cap40. Short/flat/unusable windows are missing, imputed inside training folds with missing indicators. No absolute dimension interpretation. Every example independently standardized for raw-waveform baselines; handcrafted features retain original mean/std.

Classifier search for each feature set: RBF SVC C1/10 and ExtraTrees200trees,min_leaf1/3,balanced class weights. Three-fold stratified shuffled CV seed90210 on official train; select balanced accuracy, tie earlier candidate. Freeze classifier choices before evaluating test, refit full train, test once. Raw SVC uses same C choices, standardized raw data. Score balanced accuracy(primary),accuracy,macroF1; all8 datasets reported, no removal of failures. Fixed library catch22 was attempted but C-extension build unavailable (no MSVC); do not label handcrafted baseline catch22. Gains must be measured vs all tested baselines AND same-classifier ablation to attribute to MG, with McNemar paired errors and bootstrap. Multiple-comparison correction across8datasets; these tests are screening and need independent dataset/cohort confirmation. Runtime includes MG extraction; do not assume geometric feature is cheap relative to simple statistics. No changes to manuscript.
