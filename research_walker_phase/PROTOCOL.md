# Phase-conditioned local gait tracking, fixed before outcomes

This is a SECOND distinct exploratory intervention after phase-free orbit imitation failed its validation gate. Preserve that failure. No MG from this experiment informs choices. This is local reference-gait maintenance, NOT original Walker2d locomotion from the upright default reset, NOT an autonomous unforced attractor and not a full DeepMimic reproduction.

## Reference and reset
Use exactly research_walker_imitation/reference.npz and its selected physical cycle, P=152 source samples. Same scaled17D state. A continuous externally provided phase traverses this stored cycle, with source-frame increment rho=1/(1+sqrt(2)/1000) per simulation step. Physical period T=P*dt/rho, dt.008. The .14% detuning, fixed BEFORE measurements, prevents exact integer-step repetition and duplicate nearest-neighbor samples; it is not selected for favorable MG. Linear interpolation of stored positions and velocities with cyclic indexing; scale interpolated velocities by rho for the changed time parameterization. This reference is approximate, not an exactly dynamically feasible periodic solution.

Reset uniformly in reference phase, set actual qpos/qvel from interpolated reference, horizontal position0, add independent uniform noise±.002 to qpos[1:] and±.01 to velocities. The unwrapped Walker2d health criteria remain. Both control and tracking have these IDENTICAL resets, phase observations and noise. State initialization deliberately removes the problem of entering the gait from rest. At test do not project states back to reference or filter actions.

Observation: original17 normalized Walker2d coordinates plus sin/cos(2*pi*phase/P). Extend frozen observation normalization by mean0,var1 for the two new inputs. Initialize actor/critic first-layer added columns tozero; copy all original shared anchor weights. Reset Adam for BOTH arms because input shape changed. Verify action/value equivalence to old policy before training (floating tolerance1e-6). Both arms therefore initially ignore phase. Save this common phase anchor. No observation/reward normalization updates.

## Learning
Same PPO1048576 transitions per run,8envs,512steps/env,batch256,5epochs,LR3e-5→3e-6,clip.1,targetKL.01,gamma.99,GAE.95,entropy0,vf.5,gradclip.5,actor/critic64x64 tanh,5000-step training cap. Control lambda0; tracking lambda3, no sweep. After each physics step advance the known phase and compute full-state squared error e2 to the corresponding interpolated reference (positions1, velocities5). Training reward=original walking reward -lambda*(1-exp(-e2/(2*sigma2))), with unchanged sigma2 from prior calibration. Track original rewards separately. This is a Markov phase-conditioned control task; no direct MG or recurrence penalty.

Pilot seed260, both arms. Validation73001..73005 on last3 checkpoints; choose final fixed endpoint, not best checkpoint. Gate final tracking >=4/5 healthy walks, speed>=.5, >=4 common eligible traces, original padded reward>=.9control, median paired recurrence R and fixed-phase stroboscopic dispersion D_strobe<=.8 (control medians R>=.02,D_strobe>=.001). Gate uses no MG. If passed, run ALL five pairs261..265 without replacement; otherwise stop confirmations and test both pilots. Held-out74001..74010. Fixed seed budget, no tuning after failed gate.

R and old knee-peak D unchanged. Strong held-out event: median R,D_strobe ratios<=.75,baseline R>=.02,D_strobe>=.001,>=8 common traces,original padded return>=.9control,no more than1 extra fall.
