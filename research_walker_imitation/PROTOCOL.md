Written before new training or MG. This is an exploratory follow-up; old repair/smoothing data remain unchanged. Independent means independent of MG, not unrelated to the training goal. No guarantee of active-dimension interpretation or PPO convergence.

## Motivation and intervention
The smoothing experiment reduced action differences but did not reliably improve full-state recurrence. Now train the same autonomous17-observation,6-action Walker2d policy to stay near a reference walking orbit. There is NO external phase clock, no injected periodic action and no test-time filter. Original walking reward remains, minus lambda*(1-exp(-nearest_reference_distance_squared/(2*sigma_squared))). Use full physical state qpos[1:]+qvel, positions scaled1 and velocities5. This is reference-orbit imitation, inspired by motion-imitation RL, not a reproduction of DeepMimic.

Reference chosen once from OLD research_walker_repair/seed210/step0000000/reset41001/trajectory.npz. Let P minimize full-state recurrence error over lags20..250 on that record. Among starts0..2048-P-1, choose the P-step segment with smallest endpoint state distance. All reference states are physically observed; do not average them or tune by MG. Nearest-reference distance uses the P samples as a point cloud (not interpolated segments). sigma_squared is median squared nearest distance of the entire4096-step source record, lower bound1e-6. Save source hash, period, closure, source indices and all reference points. Reference reduces translation only, retains horizontal velocity. Reward uses POST-step state. Control lambda0 shares identical wrapper but unchanged reward; log original reward separately.
