# Local project archive

This archive contains 22,582 files from the source project, preserving their original relative paths. It includes earlier manuscripts and posters, review notes, unused experiment runs, raw arrays, build outputs, and inputs for historical scripts. The source project README is saved as original_project_README.md.

The Windows environment, Git metadata, and Python caches were omitted. Forecasting, Walker2d, and the RNN generator retain the original folder layouts their scripts expect.

The previous publication code and the checks for the methodology cleanup are stored here as local snapshots.

Git includes this index. The archived files stay local.
