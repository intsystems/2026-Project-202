# Incremental MG features for smartphone activity recognition

New applied learning setting: classify six labeled activities from inertial windows on unseen people, UCI HAR official train/test subject split. No identifying personal data are sought; use public pseudonymous subject IDs only. Dataset CC BY4.0, Reyes-Ortiz et al., UCI DOI10.24432/C54S4K. Download official archive and save hashes. No test labels inspected for selection.

Input restriction: scalar norm of total acceleration and scalar norm of body gyroscope, each128 samples. These norms discard orientation, a deliberate compact input, not necessarily superior to full9-channel sensing. For each scalar, cheap features: mean,std,min,max,median,IQR,RMS,skew,kurtosis,normalized increments,lag1/4/8 ACF,spectral entropy,peak concentration,peak frequency,minimum recurrence lag4--64,permutation entropy order4,zero crossings of centered signal,linear trend. MG estimates(E6/10 crossed with tau1/2,k10,Theiler10), flags as missing not exact dimensions; very short windows forbid dimension claims. Also add delay-cloud covariance participation ratios using identical embeddings as a strong geometry competitor. Compare cheap,cheap+MG,cheap+PR,cheap+PR+MG; MG alone; supplied561-feature baseline with identical classifier/tuning budget. Additional MG is not free; report extraction costs.

Classifiers: standardized RBF SVC C1/10 and HistGradientBoosting max_iter150,max_leaf_nodes15/31,learning_rate0.1,L2=1,seed42. Internal subject validation: official training subjects ID divisible by3; others fit. Select classifier separately per feature set by subject-balanced accuracy, tie smaller complexity. Imputation/scaling fit only fitting subjects. Freeze model choices then refit on all official train subjects, evaluate official test once. Record macroF1,accuracy,subject-mean accuracy, paired subject differences/bootstrap. Main claim incremental gain vs same compact cheap+PR baseline; do not claim beat full561-feature or published state of art unless measured. Report all comparisons and selection trial count. Improvement in classification is practical utility, not proof of dynamical simplification or stopping criterion.
