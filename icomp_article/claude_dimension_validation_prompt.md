# Короткий промт для Claude Code

Нужно критически проверить выводы текущего отчёта о том, что оценки по 1-D логам якобы не восстанавливают истинную размерность.

## 1. Контролируемый синтетический эксперимент

Создай модель без backpropagation с диагональной матрицей, у которой все диагональные веса ненулевые, но во времени меняются только `k` элементов:

$$
W(t)=\operatorname{diag}(b_1+\delta_1(t),\ldots,b_D+\delta_D(t)),\qquad b_i\neq0.
$$

Для активных элементов используй независимые колебания с различными несоизмеримыми частотами:

$$
\delta_i(t)=a_i\sin(\omega_i t+\phi_i).
$$

В этом режиме истинная динамическая размерность равна `k`. Проведи sweep по `k = 1,...,6` и переходы `1 → 2 → 3 → 4 → 3 → 2`.

Обязательно добавь controls:

- `k` координат колеблются синхронно от одной фазы — истинная размерность 1;
- чистое масштабирование матрицы;
- независимый шум;
- одинаковая размерность при разной скорости и амплитуде движения.

На полученных 1-D рядах проверь LB, MG и остальные используемые оценки. Наблюдатели: фиксированные случайные проекции весов, нормы, отдельные координаты и несколько намеренно плохих проекций.

Цель — установить, существуют ли **хорошие скалярные наблюдатели**, для которых оценка:

- различает известные `k`;
- сохраняет порядок размерностей;
- устойчива к seed, шуму и длине окна;
- не принимает синхронное движение или масштабирование за многомерную динамику.

Не требуй совпадения результатов всех метрик. Разные значения по разным логам не доказывают, что истинную размерность не восстанавливает ни один лог: часть наблюдателей может терять информацию, а часть — быть пригодной. Нужно разделить их на `validated_good`, `validated_bad` и `unknown`.

## 2. Претензия к non-grokking контрпримерам

Запуски, которые не успели грокнуть до конца текущего горизонта, нельзя автоматически считать настоящими non-grokking случаями. Они являются цензурированными наблюдениями и могут грокнуть позже.

Для спорных low-data запусков нужно:

- продолжить обучение из checkpoint без изменения протокола;
- по возможности проверить несколько seed;
- различать `late grokking`, `extended non-grokking` и `insufficient budget`.

Если после падения размерности модель позднее грокнет, это мог быть ранний сигнал. Если она гарантированно не грокает на существенно более длинном горизонте, это настоящий контрпример. До такой проверки нельзя утверждать, что критерий дал false positive.

1. Какие 1-D наблюдатели действительно восстанавливают известную динамическую размерность?
2. Являются ли текущие non-grokking случаи настоящими контрпримерами или лишь незавершёнными запусками?
