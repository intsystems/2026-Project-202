# Certified stopping of a learned recurrent pattern generator

New exploratory hypothesis, fixed before data collection. Train autonomous FORCE/RLS networks to generate a figure-eight output. Use one neuron to decide when a costly full-state stability assessment is worth running; stop training only after assessment success. This is a practical conditional diagnostic policy, not a new dimension theorem. Stop-only decisions can be replayed from independent evaluation checkpoints of a deterministic training path without a curriculum counterfactual.

Networks:96 rate units, gain1.5, dt0.1, two readouts fed back into network, same target and RLS update as research_force_motion/run.py. No chaotic-start or successful-final filtering. Checkpoints0,200,500,1000,2000,4000,8000. Rollout burn1024, length2048 at frozen weights. Pilot seeds100--103; confirmation110--117 (eight seeds). Shared parameters/configuration, independent random initialization. Unsuccessful runs stay in all summaries.

Cheap inputs: one-neuron state x0 and output accuracy. MG E20,tau4,k20,Theiler156,dither123; spectral entropy; normalized squared increments; fractional-period scalar recurrence (target-period range±20%); output-aligned NRMSE and last100 training error. These are strong baselines with privileged output knowledge, explicitly included. Stable recurrence does not imply small task error, so the expensive reference includes both.

Expensive assessment: full finite-time Lyapunov spectrum computed on frozen trajectory; aligned output NRMSE<0.1, full-state fractional recurrence error<0.1, abs(lambda1)<0.005 and lambda2<-0.005. All measurements use the same finite rollout; this is an operational test, not rigorous asymptotic certification. No false acceptance relative to that test because every stopping decision runs it. Independent longer-rollout validation of chosen checkpoints will check reliability if a useful result emerges.

Pilot policies: scalar threshold in either direction, fixed grid from pilot feature quantiles0,0.1,...1 plus never/always. Check every checkpoint but call assessment only when triggered; always call at final checkpoint. Threshold selection minimizes mean training+rollout+feature+assessment time, with mean extra training steps relative to assessment-every-checkpoint <=1000. Include fixed periodic assessment every checkpoint/every2/every3 and pilot-selected fixed first-checkpoint then every subsequent checkpoint. Freeze all selected policies before confirmation outcomes. Time includes obtaining scalar rollout; exclude full spectrum used to label training corpus except when a policy calls it. Benchmark times depend on96-unit implementation; no extrapolated large-network claim.

Report end-to-end modeled cost, actual measured components, stopping step, missed opportunities/delay, success fraction, all seed outcomes, and comparison to best simple baseline. If MG loses, retain negative result. Do not tune against confirmation. Article only receives the separately authorized previous RL result during this experiment.
