N    COMPUTE COST AND CODE
     AVAILABILITY

Compute cost. Everything here runs in a few hours
on one consumer GPU and one desktop CPU. The
largest GPU item is the edge-of-stability experiment
of appendix K, which takes half an hour on a single
T4; the analysis is the more expensive half and runs
entirely on CPU, a few core-hours per experiment.

Cost of the trajectory sketch. At each logged step
the sketch keeps 4096 floats against the full parameter
vectors of appendix J: a run whose raw trajectory
would occupy 88 megabytes occupies 2.5. We train
the same configuration with and without the sketch
attached, alternating the order so that warm-up cannot
favour either. At a logging stride of ten steps the
sketch adds about six per cent to the training time.
sketch_cost.py records the measurement.

Code availability. All code, configurations and re-
sult files behind every number and figure in this paper
will be released publicly on acceptance. The figures
regenerate from the committed result files with a single
command.
